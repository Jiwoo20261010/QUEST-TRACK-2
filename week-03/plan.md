# week-03 계획서 · 내 캐릭터 데스크톱 펫

## 1. 만들 것
화면 오른쪽 아래 구석에 오리너구리 펫이 떠 있고, 내가 키보드를 칠 때마다 게임패드를 두드리듯 움직이는 프로그램.

| 상황 | 보여 줄 그림 (sheet.png 칸) |
|---|---|
| 평소 (안 칠 때) | ① 왼쪽 위 · 두 팔 들기 |
| 키를 누를 때마다 | ② 오른쪽 위 ↔ ③ 왼쪽 아래 를 번갈아 |
| 키를 멈추고 0.5초 지나면 | 다시 ① |
| 10초 동안 안 치면 | ④ 오른쪽 아래 · 졸기(Zz) |
| 졸다가 키를 치면 | 바로 깨어나서 ②③ |

- 창: 배경 투명, 테두리 없음, 늘 다른 창 위에, 작업 표시줄에 안 나옴, 크기 약 160×160
- 위치: 오른쪽 아래(작업 표시줄 바로 위)에서 시작, 마우스로 끌어서 옮길 수 있음
- 오른쪽 클릭 메뉴: "지금까지 N번 눌렀어"(보기만), "끄기"
- 누른 횟수는 프로그램이 켜져 있는 동안 메모리에만 있음. 끄면 사라짐

## 2. 어디서 돌아가는지
- Windows 11, Python 3.11.9 (이 컴퓨터에 이미 있음)
- 만드는 동안: `week-03` 에서 `python pet.py` 로 실행
- 마지막: PyInstaller 로 묶은 `pet.exe` 를 더블클릭해서 실행
- 패키지는 `week-03/.venv` (이번 주 전용 가상 환경)에만 설치해서 컴퓨터 전체에는 영향 없음

## 3. 재료
| 재료 | 쓰는 곳 |
|---|---|
| `art/sheet.png` (1254×1254, 2×2 칸, 체크무늬가 그려진 배경) | 펫 그림 원본 |
| Pillow | 그림을 4칸으로 자르고 체크무늬 배경 지우기 |
| PySide6-Essentials | 투명한 펫 창 띄우기 |
| pynput | 키를 눌렀다는 사실만 듣기 |
| PyInstaller | `pet.exe` 하나로 묶기 |

만들 파일 (예정)
- `make_frames.py`: sheet.png → `art/frames/idle.png, type_a.png, type_b.png, sleep.png` (한 번만 실행)
- `pet.py`: 펫 프로그램 본체
- `requirements.txt`: 설치할 패키지 목록
- `.gitignore`: `.venv/`, `build/`, `dist/`, `*.spec` 은 저장소에 안 올림

## 4. 단계
각 단계가 끝나면 내가 직접 확인하고, 문제없으면 그 단계만 커밋한다. 확인이 안 되면 다음 단계로 넘어가지 않는다.

### 단계 0 · 준비
- `.venv` 만들기, `requirements.txt` 쓰기, `.gitignore` 쓰기
- **설치하기 전에 나한테 먼저 물어보기** (작업실 규칙)
- 확인할 것: `.venv` 안에서 네 패키지가 import 오류 없이 불러와진다 / `git status` 에 `.venv` 가 안 보인다
- 커밋: `week-03: 펫 준비 (requirements, gitignore)`

### 단계 1 · 그림 자르기
- `make_frames.py` 로 2×2 칸을 4장으로 자르기
- 체크무늬 지우기: 그림 바깥 테두리에서 시작해 체크무늬 색(흰색·밝은 회색)만 투명하게 채워 들어가기. 검은 외곽선에서 멈추니까 눈 속 흰 점은 안 지워짐
- 확인할 것: 4장을 열어 봤을 때 둘레에 체크무늬가 없다 / 눈의 흰 점, 느낌표, Zz 가 살아 있다 / 가장자리가 너무 지저분하지 않다
- 커밋: `week-03: 펫 그림 4장 자르기`

### 단계 2 · 펫 창 띄우기
- `pet.py`: 투명·테두리 없는·맨 위 창에 `idle.png` 를 오른쪽 아래에 띄우기
- 확인할 것: 바탕화면에 펫만 보이고 네모 배경이 없다 / 다른 창을 눌러도 펫이 위에 있다 / 작업 표시줄에 안 나온다
- 커밋: `week-03: 투명 펫 창 띄우기`

### 단계 3 · 옮기기와 끄기
- 왼쪽 버튼으로 끌어서 옮기기, 오른쪽 클릭 메뉴에 "끄기"
- 확인할 것: 끌면 따라온다 / "끄기" 를 누르면 창이 사라지고 작업 관리자에도 안 남는다
- 커밋: `week-03: 펫 끌어 옮기기, 끄기 메뉴`

### 단계 4 · 타자에 맞춰 움직이기
- pynput 으로 키가 눌렸다는 신호만 받아서 횟수 +1, 그림 ②③ 번갈아, 0.5초 멈추면 ①
- 확인할 것: 메모장에 칠 때도, 브라우저에 칠 때도 움직인다 / 코드에 어떤 키인지 저장·출력하는 부분이 없다 / 펫을 꺼도 키보드가 정상이다
- 커밋: `week-03: 타자에 맞춰 펫 움직이기`

### 단계 5 · 졸기
- 10초 동안 안 치면 ④, 치면 바로 깨어남
- 확인할 것: 10초 기다리면 존다 / 키 하나 누르면 깬다
- 커밋: `week-03: 오래 안 치면 졸기`

### 단계 6 · 누른 횟수 보기
- 오른쪽 클릭 메뉴 맨 위에 "지금까지 N번 눌렀어"
- 확인할 것: 10번 치고 메뉴를 열면 숫자가 10 늘어 있다 / 파일이 새로 생기지 않는다
- 커밋: `week-03: 메뉴에 누른 횟수 보이기`

### 단계 7 · exe 로 묶기
- PyInstaller 로 `pet.exe` 하나 만들기 (그림 4장 포함, 검은 콘솔 창 없음)
- 확인할 것: `dist/pet.exe` 를 더블클릭하면 펫이 뜨고 단계 2~6 이 다 된다 / Python 을 안 켜도 돌아간다
- 커밋: `week-03: exe 묶는 방법 추가` (exe 파일 자체는 커밋하지 않음)

### 단계 8 · 앞발이 내려갈 때마다 탁 소리 내기
- 키를 눌러 ②③ 그림(앞발이 패드로 내려가는 모습)이 나올 때마다 짧은 "탁" 소리
- 소리 파일 `art/tak.wav` 는 Python 기본 기능(wave)으로 직접 만든다 (`make_sound.py`)
- 소리 재생은 Python 기본 내장 `winsound` 를 쓴다 (PySide6-Essentials 에는 소리 기능이 없음, 새 설치 없음)
- 소리를 내도 펫이 멈추거나 느려지지 않게, 재생을 기다리지 않는다
- exe 를 다시 묶어서 소리 파일도 같이 넣는다
- 확인할 것: 칠 때마다 탁 소리가 난다 / 빨리 쳐도 펫이 버벅이지 않는다 / `pet.exe` 에서도 소리가 난다
- 커밋: `week-03: 앞발 내려갈 때 탁 소리`

## 5. 하지 말 것
- 어떤 키를 눌렀는지 저장·화면 출력·로그·전송하지 않는다. 횟수만 센다 (이번 주 규칙)
- 누른 횟수도 파일에 저장하지 않는다
- 인터넷에 연결하는 코드를 넣지 않는다
- 윈도우 시작프로그램에 자동 등록하지 않는다. 관리자 권한을 요구하지 않는다
- 정해진 패키지 4개 말고 다른 것을 쓰지 않는다. 설치 전에는 꼭 묻는다
- `.venv`, `build`, `dist`, `pet.exe` 는 커밋하지 않는다
- `week-03` 폴더 밖 파일을 고치지 않는다
- 한 번에 여러 단계를 몰아서 만들지 않는다. 한 단계 → 확인 → 커밋
- GitHub 에 올리는 건 내가 하자고 할 때만

## 6. 미리 알아 둘 것
- 키를 듣는 프로그램이라 백신이 `pet.exe` 를 의심할 수 있다. 그러면 오류 문장이나 화면을 그대로 보여 주고 같이 본다
- 관리자 권한으로 켠 프로그램(일부 게임 등) 위에서 친 키는 펫이 못 들을 수 있다
- `art/sheet.png` 는 아직 커밋 전이다. 공개 저장소라서 단계 1 커밋에 같이 올라간다
